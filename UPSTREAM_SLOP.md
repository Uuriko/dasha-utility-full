# Upstream: slop.cash

This branch is the Dasha integration staging area for the MIT-licensed slop.cash project.

Upstream repository: https://github.com/SlopDotCash/slopdotcash
Upstream branch: `develop`
Upstream source architecture: React 19 + Vite + Bun, GitHub-native project manifests, contributor/reviewer skills, scoring, reward cycles, funding/settlement evidence, Cloudflare functions/workers.

The goal of this branch is not to impersonate slop.cash or replace getdasha.com. It adapts the open-source work/reward model into a Dasha-native surface while keeping upstream attribution and license requirements intact.

Initial Dasha route target: `/build`.

Production owner for getdasha.com remains the `dasha-lobby` Cloudflare Worker in `Uuriko/demigod-ops` on `worker-tree/dasha-lobby`.
